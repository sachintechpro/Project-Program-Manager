# Flowline — Value Stream Delivery

A standalone, responsive one-time Value Stream Management workspace. It guides a facilitator and Project Manager from business demand through current-state mapping, root-cause analysis, future-state design, solution prioritization, delivery planning, implementation, testing/UAT, deployment, handover and outcome measurement.

## Demo scenario
Customer Onboarding Transformation: a fictional one-time initiative targeting a reduction in onboarding cycle time from 10 business days to 3. The seeded workshop history, roles, actions, decisions, risks and process timings are illustrative only.

## Features
- 11-stage guided lifecycle with stage notes, output checklists and progress
- Suggested attendees and PM facilitation prompts at each stage
- Meeting records that can be saved incrementally
- Current-state and future-state process maps with editable steps and time estimates
- Decision, action, risk and dependency registers
- Outcome measurement and closure checklist
- Local autosave and JSON export
- Responsive desktop, tablet and mobile layout

## Run
Open index.html in a modern browser. No build step or external dependencies. Workspace data is stored in browser localStorage on the current device. Use Export workspace to back up or move the data.

## Scope
This version intentionally supports one-time delivery only. It does not include ARTs, PI Planning, Release Trains or continuous delivery management.
